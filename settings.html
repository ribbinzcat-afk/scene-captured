Scene Captured

เลือกข้อความในแชท แล้วให้ AI เขียน image prompt จากซีนนั้นให้ ก่อนส่งต่อไปเจนภาพ (เน้น NovelAI) — เปิดใช้ผ่านปุ่มที่ข้อความ หรือลากเลือกข้อความในแชท

การเจน prompt
ไม่เลือก = ใช้ API หลักของ SillyTavern ที่ตั้งไว้อยู่แล้ว (ปกติไม่ต้องแตะ) ให้ AI รู้จักหน้าตา/ลักษณะตัวละครแม่นขึ้น แม้ข้อความที่เลือกจะไม่ได้พูดถึงเลยก็ตาม มีประโยชน์ถ้าตัวคุณเองก็ปรากฏอยู่ในภาพด้วย เผื่อมีรายละเอียดสถานที่/เครื่องแต่งกาย/สิ่งของเฉพาะที่ตั้งไว้ใน lorebook

การแทรกรูป
ไม่เปิด = จะเปิดหน้าต่างให้ดู/แก้ prompt ก่อนเสมอ (แนะนำสำหรับมือใหม่ จะได้ตรวจก่อนเจนจริง)
Token นี้เก็บเป็น plaintext ใน settings.json ของ SillyTavern — ระวังอย่าแชร์ไฟล์นี้ให้ผู้อื่น ถ้ายังไม่ได้เปิด ให้เปิด enableCorsProxy: true ใน config.yaml ของ SillyTavern แล้วรีสตาร์ทเซิร์ฟเวอร์ก่อน เปิดแล้วจะมีตารางให้เลือกตำแหน่งแต่ละตัวละครตอนแก้ prompt — ไม่เปิดก็ใช้ได้ปกติ แค่ไม่กำหนดตำแหน่งตายตัว
ทดสอบการเชื่อมต่อ
โหมดนี้ต้องกรอกค่าทางเทคนิคเอง (URL, JSON) เหมาะกับผู้ที่มี API ของ provider อื่นอยู่แล้วและรู้จักการเขียน JSON แทรกเป็น header ให้อัตโนมัติ (ไม่ต้องเขียนเองในช่อง Headers ด้านล่าง) — เก็บเป็น plaintext ใน settings.json
